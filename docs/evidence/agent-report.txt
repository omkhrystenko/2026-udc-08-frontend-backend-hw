Усе готово, 13/13 тестів зелені (9 попередніх + 4 нових).

Що змінив:

- **БД** (`src/db.js`): додав колонку `archived INTEGER NOT NULL DEFAULT 0` до `notes`, з міграцією через `PRAGMA table_info` для існуючих файлів БД — старі дані не втрачаються.
- **API** (`src/app.js`):
  - `GET /api/notes` тепер приймає `?archived=1` для перегляду архіву (за замовчуванням — активні нотатки).
  - `GET /api/notes/:id` заодно доскопив до `user_id = ?` (раніше повертав чужу нотатку за самим лише id — це порушувало основну гарантію авторизації застосунку) і додав поле `archived` у відповідь.
  - Новий `PATCH /api/notes/:id/archive` перемикає стан архівування: валідує id, шукає нотатку **лише серед нотаток викликача**, повертає 404 якщо це не її нотатка або нотатки не існує, інакше перемикає `archived` і повертає оновлену нотатку.
- **UI** (`public/`): кнопка «Архівувати» / «Повернути з архіву» біля кожної нотатки; вкладки «Активні» / «Архів» для перемикання списків, кожен зі своїм порожнім станом («Нотаток поки немає.» / «Архів порожній.»); форма додавання нотатки прихована у вкладці архіву.
- **Тести** (`test/api.test.js`): 4 нових тести на `PATCH /api/notes/:id/archive` — архівування, повернення назад, авторизаційна перевірка (чужа нотатка → 404, не впливає на чужий список), 404 для неіснучої нотатки.
